How to set up your Telegram bot
  1. Open Telegram and message @BotFather.
  2. Send /newbot and follow its prompts (it'll ask for a name, then a username ending in bot).
  3. BotFather replies with a token like 123456789:AA... — copy it and paste it below.
  4. Open a chat with your new bot (BotFather gives you a direct link) and send it any message — e.g. "hi". This is required once, so the bot has a chat to reply to.
  5. Paste the token below, save, then click Find my Chat ID to auto-fill the last step.
