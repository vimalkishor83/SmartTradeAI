How this works

Individual alerts go to each subscriber's own Telegram chat (they connect it themselves in Settings → Notifications). The toggles below are the master on/off switch per category — turning one off stops it for every subscriber, even those who've connected their own chat.

Group channels are separate shared destinations you create below — e.g. a "Crypto Signals" group and a "Forex & Gold" group can exist side by side, each getting a different mix of alerts for different markets. To add one:

  1. One platform-wide bot handles every channel (not any individual subscriber's own bot) — if TELEGRAM_BOT_TOKEN isn't set on the server yet, get a token from @BotFather and add it to the deployment first.
  2. In Telegram, create a group (not a channel) and add your bot to it.
  3. Send any message in that group — e.g. "hi". This is required once, so the next step has something to find.
  4. Open this URL in a browser, replacing <token> with the bot token: https://api.telegram.org/bot<token>/getUpdates
  5. Find "chat":{"id": in the response — that number (it will be negative, e.g. -1001234567890) is the group's Chat ID.
  6. Click "Add Channel" below, paste the Chat ID, pick which markets and categories it should receive, then use its "Test" button to confirm it actually works.
Alert Categories

Per category, pick which markets go to Individual subscribers (each subscriber's own Telegram chat, Settings → Notifications) and which go to Group channels (any matching channel below) — independently. E.g. crypto signal alerts can go to both, forex signal alerts to the group only, gold to neither. Leave a market unchecked in a column to turn it off for that column only.
