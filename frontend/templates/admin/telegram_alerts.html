TELEGRAM_BOT_TOKEN isn't set on the server yet — nothing below can send anything until it is. This is a server secret (not editable from here); it needs adding to the deployment's environment config.
How to set this up
  1. This uses one platform-wide bot (not any individual subscriber's own bot) — if TELEGRAM_BOT_TOKEN isn't configured on the server yet, get a token from @BotFather first and have it added to the deployment.
  2. In Telegram, create a group (not a channel) and add your bot to it.
  3. Send any message in that group — e.g. "hi". This is required once, so the next step has something to find.
  4. Open this URL in a browser, replacing <token> with the bot token: https://api.telegram.org/bot<token>/getUpdates
  5. Find "chat":{"id": in the response — that number (it will be negative, e.g. -1001234567890) is the group's Chat ID. Paste it below and save.
  6. Pick which markets and which alert categories should go to this group, then use "Send a message now" to confirm it actually works.
